# Memsum 리디자인 명세 (2026-10) — "형광펜 & 코발트"

컨셉은 그대로(스크린샷 자동 감지 → 글자 인식 → 정리 → 캘린더/택배 → 일요일 5줄 리포트).
바꾸는 것은 시각 언어 전부. 이 문서가 모든 작업의 기준이다. 기존 `디자인시스템.md`의 라벤더/아이보리/코랄·9닷 로고 규칙은 폐기한다.

## 1. 한 줄 정체성
"스크린샷 더미에서 쓸모 있는 글자만 형광펜으로 그어 뽑아내는 앱."
재료: 종이, 잉크, 코발트 펜, 형광펜, 스크린샷의 크롭 모서리, 타임스탬프.

## 3. 서체
- **Wanted Sans** (정적 4종: Regular 400 / SemiBold 600 / Bold 700 / Black 900) — 한글·라틴 전부. Pretendard 폐기.
- **JetBrains Mono Medium** — 시각·날짜·개수·운송장·작은 머리표(eyebrow). 라틴/숫자 전용(한글 넣지 말 것 → 한글 섞이면 Wanted Sans로).
- 안드로이드는 fontWeight로 굵기를 못 고르므로 **굵기마다 별도 fontFamily 이름**을 쓴다. 공용 `<Text variant=…>` 컴포넌트가 이를 숨긴다. 화면 코드에서 RN `Text` 직접 사용 금지.

## 4. 구조 장치 (의미가 있을 때만)
- **머리표(eyebrow)**: mono, ink2, 예 `10월 1주 · 38장` / `09:41 · 택배`. 섹션 라벨은 이걸로 통일(회색 작은 한글 라벨 반복 폐기).
- **형광펜 표시 `<Marked>`**: 문장 속 핵심 구절 뒤에 marker 사각형을 깔아 강조. 등장 시 왼→오로 그어지는 모션(약간 기울기 -1.5°, 높이 글자의 70%, 아래쪽 정렬). 화면당 1곳만.
- **크롭 모서리**: 스크린샷 썸네일/로고에 쓰는 L자 모서리 4개. 브랜드 마크.
- 번호(01/02…)는 리포트 순위처럼 실제 순서일 때만.

## 5. 시그니처 모션: "스캔"
`<ScanReveal>` — 스크린샷 이미지 위로 코발트 스캔선(2px + 아래로 번지는 12% 그라데이션 꼬리)이 위→아래로 훑고(900ms), 지나간 자리의 글자 영역에 형광펜 박스가 순서대로 그어진 뒤(각 120ms 간격), 이미지가 작아지며 결과 카드 자리로 빨려 들어간다.
- 글자 영역: OCR 블록 좌표가 있으면 사용, 없으면 의사 행 4~6개.
- 쓰는 곳: 캡처 시트 처리 단계(핵심), 온보딩 1페이지, 스플래시(축약 600ms).
- 그 외 화면은 조용히. 한 화면에 연출된 순간은 하나.

공통 모션 규칙
- 눌림: 투명도 대신 `scale 0.97` 스프링(snappy). `PressableScale` 공용 컴포넌트.
- 목록 등장: 첫 진입만 아래→위 8px + 페이드, 40ms 간격, 최대 6개까지만 지연.
- 숫자: 카운트업(600ms, decel).
- 탭 전환 인디케이터: 레이아웃 스프링으로 미끄러짐.
- `useReducedMotion()`이면 모든 연출을 즉시 최종 상태로.
- 햅틱: 스캔 완료(성공), 리포트 1위 공개(약하게)만.

## 6. 화면 방향
- **탭바**: 바닥에서 떨어진 잉크색(#0D0E12) 알약형 플로팅 바, 아이콘만+활성 탭 아래 형광펜 점. 가운데 "가져오기"는 코발트 원. 자동 감지 켜짐이면 탭바 위 작은 mono 표시 `● 감지 중` (꺼짐이면 표시 없음).
- **홈**: 인사말 폐기. 맨 위 머리표 `10월 1주 · 38장`, 그 아래 display 헤드라인 한 문장 + `<Marked>` (예: "이번 주, [일정 4개]를 건졌어요" / 데이터 없으면 "아직 건진 게 없어요"). 다음 "다가오는 것"(일정·택배)을 구분선 목록으로, 이어서 최근 캡처 3열 그리드(크롭 모서리 썸네일), 주제별 묶음은 가로 스크롤 칩.
- **캡처 시트**: 처리 중 = ScanReveal 풀 연출. 결과 = 제목(title) + 뽑힌 항목들이 형광펜 박스에서 튀어나와 행으로 정렬.
- **상세**: 시스템 헤더 대신 공용 Header. 이미지 → 제목 → 뽑힌 일정/택배 → OCR 원문은 접힘(“인식된 글자 보기”).
- **자료실/검색**: 3열 그리드로 통일(홈과 동일), 검색창은 밑줄형.
- **캘린더**: 날짜를 mono 큰 숫자 왼쪽 열 + 내용 오른쪽의 타임라인 행.
- **주간 리포트 (일요일 의식)**: mega 순위 숫자 1~5가 차례로 떨어지며 굴러 들어오고(1.2s 전체), 각 줄은 한 문장 + 원본 썸네일. 1위 줄만 형광펜.
- **설정**: 구분선 그룹, 뒤로가기 제거(탭이므로).
- **빈 상태**: 중앙 정렬 원형 아이콘 패턴 폐기. 왼쪽 정렬 헤드라인 + 할 일 버튼 하나 + 크롭 모서리로 그린 빈 프레임.
- **온보딩**: 3페이지. 1) ScanReveal 데모 2) 자동 감지 설명 + 권한 3) 일요일 5줄 리포트 미리보기. 문구는 짧고 구체적.

## 7. 문구 톤
- 해요체로 통일. 반말 금지. 위로·감탄("천천히 시작해도 괜찮아요", "잊을 뻔했죠?") 금지.
- 용어 통일: "5줄 리포트", "자동 감지", "가져오기", "건졌어요/정리했어요" 중 하나로(정리 = 기능 동사, 건지다 = 홈 헤드라인 한정).
- 오류: 무엇이 안 됐고 어떻게 하면 되는지. 서버 원문 노출 금지.

## 8. 앱 아이콘·스플래시
- 아이콘: 코발트 바탕, 종이색 크롭 모서리 4개로 만든 프레임, 그 안을 가로지르는 형광펜 막대 1개(살짝 기울기). 단색 아이콘은 모서리+막대 실루엣.
- 스플래시: 라이트 paper / 다크 ink 바탕, 같은 마크.
