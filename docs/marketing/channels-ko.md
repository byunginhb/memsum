## 1. GeekNews — Show GN

**규칙 요약(확인함):** 직접 만든 서비스·앱만 등록, 직접 써 볼 수 있어야 함(소개 페이지만 있는 건 불가), 같은 프로젝트는 주요 버전업 이후에만 재등록, 짧은 기간 반복 등록 금지.
**주의:** 이전에 Memsum을 Show GN에 올린 적이 있다면 이번 1.1.0이 "주요 버전업"으로 인정되는지 애매해요. 올린 적이 없으면 그대로 진행, 올린 적이 있으면 이번엔 건너뛰어요(확인 필요).

- **URL 칸:** `{링크:geeknews}` (Play 링크. 써 볼 수 있는 곳으로 바로 보내야 해서 랜딩이 아닌 Play로)
- **제목:**

```
Show GN: Memsum – 스크린샷 속 일정을 읽어 캘린더와 일요일 5줄로 다시 알려 주는 안드로이드 앱
```

- **본문:**

```
안녕하세요. 혼자 만든 안드로이드 앱 Memsum(멤섬)을 소개해요.

사진첩 스크린샷 폴더에 1,800장을 쌓아 두고도 그 안에 있던 약속을 놓쳤어요. 찍을 때는 나중에 보려고 했는데, 나중에 다시 열어 보지 않았어요. 그래서 찍어 두기만 하면 대신 기억했다가 놓치기 전에 꺼내 주는 앱을 만들었어요.

[동작 방식]
1. 새 스크린샷을 찍으면 "Memsum에 저장할까요?" 알림이 와요. [저장]을 누르면 앱을 열지 않아도 처리돼요.
2. 기기에서 글자를 읽고(한국어 지원), 서버에서 한 줄 제목·한 줄 요약·6가지 분류(마케팅·일정·영수증·쇼핑·정보·기타)를 붙여요.
3. 날짜가 보이면 일정으로 뽑아요. 날짜가 글에 정확히 적혀 있으면 '날짜 확실', "다음 주"처럼 모호하면 '확인 필요'로 표시하고, 자동 등록은 '날짜 확실'인 일정만 해요.
4. 홈 맨 위에 다가오는 일정을 D-day 순으로 보여 주고, 일정 전날 저녁에 내일 일정을 알림 한 번으로 묶어 알려 줘요.
5. 일요일 저녁 7시, 그 주 캡처 중 다시 볼 만한 5개를 골라 '5줄 리포트'로 보내요.
6. 검색하면 제목뿐 아니라 캡처 속 글자까지 찾아요.
7. 예전에 찍어 둔 스크린샷도 사진첩에서 골라 불러오면 같은 방식으로 정리해요.

[신경 쓴 부분]
- 백그라운드 감지: MediaStore 이미지에 JobScheduler 콘텐츠 URI 트리거를 걸어 새 스크린샷만 골라요. 일반 사진은 건드리지 않고, 자동 감지는 설정에서 끌 수 있어요.
- 글자 인식은 기기에서 먼저 하고, 정리·요약은 서버 함수에서 gpt-4o-mini로 해요. OpenAI에는 인식된 글자만 보내고 이미지는 보내지 않아요. 원본 사본은 본인만 접근할 수 있는 비공개 저장소에 둬요.
- 회원가입 없이 익명으로 바로 시작해요. 구글 캘린더 권한은 일정 추가에만 쓰고 기존 일정은 읽지 않아요.
- 설정에서 서버에 올라간 내 데이터를 한 번에 지울 수 있어요.
- 무료이고 광고가 없어요.
- 스택: Expo React Native + Kotlin 네이티브 모듈, Supabase(Postgres·Edge Functions·Storage).

[지금 상태]
- Android만 있어요. iOS는 준비 중이고, https://memsum.app 에서 출시 알림을 신청할 수 있어요.
- 5줄 리포트는 한 주에 스크린샷이 5장 넘게 모여야 채워져요.
- 혼자 만들고 있어서 거친 부분이 있어요. 써 보고 불편했던 점을 댓글이나 byunginhb@gmail.com으로 알려 주시면 직접 답할게요.
```

## 3. 클리앙

**규칙 확인 결과(2026-10-05 확인):**
- **새로운소식 게시판:** "본인이 소속되어 있거나 관련 있는 단체의 정보는 게시할 수 없다", 광고로 삭제되고 이용 제한 가능. 운영진의 사전 서면 허가가 있을 때만 예외 → **올리지 않아요.**
- **사용기 게시판:** 본인이 직접 구매·경험한 제품만, 홍보 목적 글 금지 → 개발자 본인 앱 사용기는 홍보로 판단될 가능성이 높아 **올리지 않아요.**
- **사이트 이용규칙 제2조:** "일반적인 회원으로 가장하여 홍보성 게시물을 작성하여서는 안 됩니다", "바이럴마케팅이나 전문적인 판매, 홍보(블로그, 동영상, 앱 등)를 위한 활동은 금지" → 모두의공원·아무거나질문 등에 우회해서 올리는 것도 **하지 않아요.** 지인에게 대신 올려 달라고 부탁하는 것도 같은 규칙 위반이에요.
- **직접홍보 게시판:** 기업회원만 작성 가능, 유료(7일 44,000원 / 15일 66,000원 / 30일 99,000원), 관리자 승인 후 노출. 앱 개발자를 명시적으로 막지는 않아요.

사진첩을 열면 '스크린샷' 폴더가 따로 있어요. 제 폴더엔 1,800장이 넘게 쌓여 있었어요. 영수증, 약속 메시지, 할인 쿠폰, 나중에 읽으려던 글. 계속 찍기만 하고 다시 보는 일은 거의 없었어요.

그러다 그 안에 있던 약속을 놓쳤어요. 분명 캡처해 뒀는데, 다시 열어 보지 않았으니 없는 것과 같았어요.

■ 왜 만들었나

스크린샷은 가장 쉬운 메모예요. 손가락 두 개면 끝나요. 문제는 그다음이에요. 찍은 뒤에 캘린더로 옮기고, 폴더를 나누고, 태그를 붙이는 일은 결국 안 하게 돼요. 메모 앱도 써 봤지만 한 달쯤 지나면 손이 가지 않았어요.

그래서 방향을 바꿨어요. 정리를 제가 하는 게 아니라, 찍어 두기만 하면 앱이 대신 읽고 기억했다가 놓치기 전에 다시 꺼내 주면 되겠다고요. 그렇게 혼자 Memsum(멤섬)을 만들었어요. Memory와 Summary를 합친 이름이에요.

■ 문제는 '찍은 뒤'에 있었어요

캡처한 순간엔 다 기억할 것 같아요. 그런데 화요일에 찍은 병원 예약은 금요일이면 다른 캡처 수십 장 밑에 깔려 있어요. 찾으려면 사진첩을 한참 내려야 하고, 무엇을 찍어 뒀는지조차 기억나지 않을 때가 많아요.

필요한 건 세 가지였어요.
1) 찍을 때 따로 할 일이 없을 것
2) 날짜가 있으면 캘린더에 들어갈 것
3) 놓치기 전에 한 번은 다시 알려 줄 것

■ 기능 정리

- 새 스크린샷 자동 감지: 다른 앱을 쓰는 중에도 알림으로 물어봐요. 일반 사진은 건드리지 않아요.
- 글자 인식: 기기에서 글자를 읽고(한국어 지원), 오타와 줄바꿈을 다듬어요.

- 검색: 캡처 속 글자로 찾기.
- 예전 스크린샷: 사진첩에서 골라 불러올 수 있어요.
