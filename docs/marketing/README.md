## 4. 측정 방법

### 4-1. Play Console (주 측정 도구)

- **어디서:** Play Console → 사용자 확보(또는 "통계") → 획득 보고서 → 스토어 등록정보 방문자·설치자, 획득 채널 중 **"추적 채널(UTM)"**.
- **무엇을:** utm_source별 스토어 방문자 수, 설치자 수, 전환율(설치 ÷ 방문). 기간 10/06~10/19, 비교 기간 9/22~10/05.
- **같이 볼 것:** "Google Play 검색" 유입 방문자(ASO 기준값), 국가·언어별(영어권 채널 효과).
- **한계:** 숫자가 작으면 "기타"로 묶일 수 있어요. 웹(memsum.app)을 거쳐 설치한 사람은 채널이 구분되지 않아요.

### 4-2. PostHog (앱 안 행동)

- 운영 빌드에 키가 있을 때만 동작해요(사전 확인 3번).
- 앱이 보내는 이벤트는 6종이에요: `photo_imported`, `capture_completed`, `report_viewed`, `report_item_opened`, `report_feedback`, `report_coachmark_dismissed`.
- **볼 지표:**
  - 일별 신규 익명 사용자 수 → 게시 날짜와 겹쳐 보기(어느 날 글이 효과 있었나)
  - 활성화율: 신규 사용자 중 7일 안에 `capture_completed` 1회 이상
  - 일요일 리포트 도달: 10/11, 10/18의 `report_viewed` 사용자 수, `report_item_opened` 비율
  - `report_feedback` 좋아요/필요 없었어요 비율
- **한계:** 설치 경로(Install Referrer)를 읽지 않아 채널별로 나눌 수 없어요.

### 4-3. 정성 지표

- 채널별 댓글 수와 그중 기능 질문·버그 제보 수, 피드백 메일 수, "날짜를 잘못 잡았다" 사례 수(제품 개선 우선순위로 바로 연결).
